# 《探窗》AI短片视觉素材方案

## 一、项目定位

歌曲：《探窗》

核心主题：

> 戏中人唱尽旧情，戏外人已成陌路。

整体方向：

-   古风爱情悲剧
-   江南水乡美学
-   戏曲文化氛围
-   东方电影感
-   AI古风微电影

------------------------------------------------------------------------

# 二、核心人物设定

## 女主：戏班花旦

身份：

江南戏班名角。

人物特点：

-   20-23岁东方女性
-   清雅秀丽
-   温婉含情
-   戏妆艳丽
-   卸妆后清冷孤独

服装：

台上：

-   红色戏服
-   凤冠霞帔
-   水袖
-   精致戏曲妆容

台下：

-   青绿色素雅长裙
-   白玉簪
-   简洁发髻

要求：

保持全片人物脸部一致。

------------------------------------------------------------------------

## 男主：远游书生

身份：

江南书生，赴京赶考。

特点：

-   白衣
-   儒雅温润
-   手持折扇
-   少年气质

剧情：

少年相识，远游求仕，归来已晚。

------------------------------------------------------------------------

# 四、摄影风格

推荐：

-   4K电影质感
-   35mm胶片摄影
-   东方古典美学
-   柔和光影
-   浅景深
-   烟雨江南

色彩：

前期：

-   暖色
-   春日
-   灯火

后期：

-   青灰
-   雨夜
-   孤灯

------------------------------------------------------------------------

# 五、AI生成统一限制

必须加入：

保持同一男女主角色贯穿整个视频，脸部特征一致，服装统一，真实人体比例，电影摄影风格。

避免：

-   动漫
-   插画
-   塑料皮肤
-   现代服饰
-   现代建筑
-   人物脸部变化

------------------------------------------------------------------------
